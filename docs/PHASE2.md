# المرحلة الثانية: مكتبة الصور والمرجعيات

## الاستخدام

من «الأصول والمرجعيات» ارفع صور JPG أو PNG أو WebP، وصنّفها: شغل منفّذ، خامة، مرجع تصميم، أو لوجو وهوية. لكل صورة اسم ووصف وخامة مسجلة من المستخدم، مع بحث وتصفية ومعاينة وتعديل.

اختيار «استخدام في التوليد» يضيف الصورة لطلبات الأفكار والكاليندر والبوست الفردي؛ الحد أربع صور للطلب. عدم اختيار صور يبقي مسار التوليد النصي متاحًا. الصور غير المتاحة توقف الطلب برسالة واضحة بدل تجاهلها. كل بوست وفكرة يحتفظان ببيانات الصور المرسلة مع طلبهما، وتعرض معاينة البوست هذه الصور.

«وصف الصورة بالذكاء الاصطناعي» يرسل الصورة إلى Gemini ويرجع وصفًا مقترحًا في خانة الوصف. الوصف يحتاج مراجعة وحفظًا من المستخدم؛ بيانات البراند والموديل والمنشأ لا تُستنتج من الصورة. تميّز تعليمات التوليد بين الشغل المنفّذ ومراجع التصميم.

## الصور والحفظ

- حد الملف الأصلي 10 ميجابايت، وعشر صور في الرفع الواحد. تجهيز الصورة داخل المتصفح يحافظ على النسب ويحد أطول ضلع عند 1600 بكسل وحجم الصورة المحفوظة عند 600 كيلوبايت، مع محاولة ضغط WebP.
- ملفات الصور منفصلة عن JSON مساحة العمل، في IndexedDB وعلى ريبو البيانات المُعد في الإعدادات عند تفعيل المزامنة. لا توجد خدمة تخزين إضافية. ظهور الصور في ريبو عام يتبع صلاحيات وظهور ذلك الريبو؛ ملفات الصور ليست روابط عامة مستقلة عن إعدادات المزامنة.
- كل ملف صورة سحابي JSON أقل من حد GitHub Contents API البالغ 1 ميجابايت. الصور تُجلب عند عرض المكتبة أو معاينة البوست أو التوليد، وتُستخدم النسخة المحلية عند توفرها. بيانات كل شركة معزولة بمسار ومفتاح مستقلين.
- إعادة محاولة المزامنة تشمل الصور المعلقة قبل بيانات مساحة العمل. بطاقات الصور تبيّن الحفظ المحلي أو اكتمال المزامنة.
- «إزالة من المكتبة» تزيل بطاقة الصورة واختيارها، وتترك البكسلات المرتبطة بالبوستات والأفكار ونسخة الاسترجاع متاحة. لا تنفذ حذفًا نهائيًا للملفات.
- النسخة الاحتياطية الكاملة إصدار 2 تضم ملفات الصور، بما فيها مراجع البوستات والأفكار حتى بعد إزالة البطاقة من المكتبة. يستمر قبول نسخ إصدار 1 القديمة الخالية من الصور. استيراد نسخة ناقصة الصور مرفوض قبل استبدال البيانات.
- حد استيراد النسخة 50 ميجابايت، وحد مجموع بيانات الصور المصدّرة 40 ميجابايت. مفاتيح الربط غير مضمّنة. مسح بيانات الموقع يزيل النسخة المحلية؛ التنزيل الكامل أو المزامنة المكتملة هما طريق الاستعادة على جهاز آخر.
- توليد صورة الريفرنس المقترحة الموجود سابقًا يستخدم الاتجاه البصري النصي؛ ليس تعديلًا للصورة المرفوعة.

## صيغة الطلب والتحقق

صور التوليد تُرسل كـ `inlineData` مع `mimeType` و`data` مع نصوص بيانات المرجع، وفق [مرجع Google الرسمي](https://ai.google.dev/api/caching#Part). إعادة محاولات التوليد تحمل نفس الصور؛ مراجعة منع التكرار النصية لا تعيد إرسالها بلا داعٍ. لا تحفظ نسخ البكسلات في كل بوست أو فكرة.

شغّل:

```sh
node tests/phase1.test.cjs
node tests/phase2.test.cjs
```

الاختبارات تحاكي IndexedDB وDOM وCanvas وGemini وGitHub، وتفحص البايتات المرسلة والحفظ والتزامن والاسترجاع وتاريخ المراجع. لم تُنفذ قراءة صورة حقيقية بمفتاح المستخدم أو مراجعة بصرية في متصفح كمبيوتر وموبايل.
