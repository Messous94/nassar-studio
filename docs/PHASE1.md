# المرحلة الأولى: حماية البيانات وثبات الحفظ

- النسخة الاحتياطية من الإعدادات تخص الشركة المفتوحة وتشمل مساحة العمل كاملة. لا تشمل مفاتيح Google أو GitHub أو قواعد المنصات العامة أو باقي الشركات.
- الاستيراد يقبل نسخ التطبيق بالإصدار 1 لنفس الشركة، بحد 20 ميجابايت، ويتحقق من البيانات قبل طلب الاستبدال.
- الحذف والاستبدال والاسترجاع من GitHub يحتاجون تأكيدًا. يحتفظ التطبيق بنسخة محلية واحدة قبل آخر تغيير كبير لكل شركة. زر الاسترجاع يعيدها، ويحفظ الحالة التي استبدلها لتسهيل الرجوع.
- الكاليندر الجديدة تُضاف افتراضيًا. الاستبدال يحتفظ بالقديمة حتى يكتمل التوليد ويراجع التطبيق الرد.
- الحفظ المحلي يتم بمعاملة IndexedDB كاملة، مستقلة عن انتظار الشبكة. فشل الرفع يترك البيانات والتعديلات المعلقة محفوظة على الجهاز حتى بعد إعادة الفتح.
- إعادة محاولة المزامنة من الإعدادات ترفع البيانات المعلقة. تعارض نسخة GitHub لا يُحل بالكتابة فوقها تلقائيًا؛ نزّل نسخة احتياطية وراجع بياناتك قبل الاسترجاع الصريح.
- بيانات الجهاز ونسخة الاسترجاع تُفقد عند مسح بيانات الموقع؛ النسخة الاحتياطية المنزلة منفصلة عنها.

## التحقق

شغّل `node tests/phase1.test.cjs` باستخدام Node.js 18 أو أحدث. الاختبارات بدون dependencies وتحاكي IndexedDB وGitHub وواجهة التطبيق؛ تشمل انقطاع الشبكة، تعارض النسخ، فشل المعاملة المحلية، الاسترجاع، وإضافة/استبدال الكاليندر.

لم يُنفذ اتصال Gemini أو مزامنة بيانات GitHub حقيقية بالمفاتيح الشخصية. الاختبار البصري على الكمبيوتر والموبايل غير مكتمل بسبب عدم وصول المتصفح إلى خادم المعاينة المحلي.
